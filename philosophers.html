How to Observe

This application simulates how an Operating System manages multiple processes competing for shared resources.

  1. The Setup: There are 5 Philosophers (Processes) and 5 Chopsticks (Resources).
  2. The Rule: To move into the Green State, a philosopher must lock two semaphores.
  3. Watch for the "Wait": When a philosopher turns orange, notice their neighbor is likely green. This demonstrates Mutual Exclusion.

Operating System Theory

The Dining Philosophers problem (Edsger Dijkstra, 1965) is the standard model for understanding Concurrency Control.

Deadlock

A state where every process is waiting for a resource held by another, creating a permanent freeze.

Starvation

When a process is perpetually denied the resources it needs to make progress.

Mutex

A "Mutual Exclusion" object that acts as a lock to ensure only one process accesses a resource.

Critical Section

The segment of code (or time) where shared resources are accessed—here, it is the 'Eating' state.

Our Solution: Resource Hierarchy

We solve the deadlock by breaking the Circular Wait condition. In our simulation, we number the philosophers 0–4. While P0–P3 pick up their Left chopstick first, P4 picks up its Right chopstick first. This simple change ensures that at least one philosopher can always eat.
